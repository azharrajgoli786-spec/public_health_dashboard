Our mission

Provide clear, accessible, and reliable health information for the public — dataset numbers presented simply, plus educational disease pages based on WHO, MoHFW, and NCDC public guidance. Transparent health data supports early outbreak awareness and faster response, contributing to a more aware, informed, and healthier society.

Why trust this dashboard

Trusted data

Case counts come only from the project dataset; guides cite WHO, MoHFW and NCDC public guidance.

Clear dates

Every page shows dataset freshness and when the disease library was last updated.

Accessible insights

Plain charts, sortable tables and honest empty states anyone can read.

Informed decisions

Supporting evidence-based thinking — never prescriptions or dosages.

About the sample dataset

This project ships with a sample dataset so the interface can be demonstrated without publishing identifiable or unreleased figures. Please read the numbers accordingly:

  • These are not surveillance figures. No figure in this dashboard should be read as real disease activity in India.
  • There is no reporting period. The sample file carries no date, so none is shown. A file’s modification timestamp moves whenever the file is touched, so it is not used as a data vintage.
  • Rows marked est are modelled, not reported. {{ stats.estimated_diseases|join(', ') }} are reconstructed for every state as a share of that state’s dataset total, with a fixed per-state variation so the values are not copy-pasted across states.
  • District coverage varies widely — a large state may show many reporting districts while a small one shows only a few.
  • Reference data is separate from surveillance data. Populations ({{ site.population_vintage }}) and district counts ({{ site.district_vintage }}) are public reference figures, used only to normalise counts — for example to rank states by cases per lakh.

Dropping a real IDSP outbreak file named idsp_outbreak_data.csv or idsp_real_data.csv next to app.py switches the dashboard to real data automatically.

Frequently asked questions

Is this live, real-time data?

{% if site.is_demo %}No. Case counts come from a sample dataset used for interface testing — they are not official surveillance figures, and there is no reporting period.{% else %}Data refreshes only when the dataset file is updated; it is not a live feed.{% endif %} The disease library is updated separately (last: {{ site.library_updated or 'date not available' }}).

Can I use it for medical advice?

No. Disease pages are general educational information based on WHO, MoHFW, and NCDC public guidance. They do not replace consultation with a qualified healthcare professional, and no prescription medicines or dosages are listed.

What do the case numbers mean?

They are reported case counts per state and district from the project dataset — a measure of reporting volume, not disease prevalence. Rows tagged est are modelled estimates rather than reported entries.

What should I do in an emergency?

Call 108 / 102 or go to the nearest emergency department. Do not rely on this dashboard in an emergency.
