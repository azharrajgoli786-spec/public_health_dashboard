About the sample dataset

This project ships with a sample dataset so the interface can be demonstrated without publishing identifiable or unreleased figures. Please read the numbers accordingly:

  • These are not surveillance figures. No figure in this dashboard should be read as real disease activity in India.
  • There is no reporting period. The sample file carries no date, so none is shown. A file’s modification timestamp moves whenever the file is touched, so it is not used as a data vintage.
  • Rows marked est are modelled, not reported. {{ stats.estimated_diseases|join(', ') }} are reconstructed for every state as a share of that state’s dataset total, with a fixed per-state variation so the values are not copy-pasted across states.
  • District coverage varies widely — for example, a large state may show many reporting districts while a small state shows only one or two. The states table states how many of each state’s districts appear.
  • Reference data is separate from surveillance data. Populations ({{ site.population_vintage }}) and district counts ({{ site.district_vintage }}) are public reference figures, used only to normalise counts — for example to rank states by cases per lakh.

Dropping a real IDSP outbreak file named idsp_outbreak_data.csv or idsp_real_data.csv next to app.py switches the dashboard to real data automatically.
