# Public Health Dashboard

A dashboard for analyzing and visualizing public health data.

## Technologies Used
- Python
- Pandas
- Flask
- HTML
- CSS
- JavaScript

## Features
- Engaging home page: hero with live data snapshot, disease + location finder, stat cards, top-states chart, quick-access cards, and a data freshness strip
- Disease and location finder (`/find`) returning dataset rows plus the matching health guide
- States page: region filter, sort, in-table search, pagination, CSV export, and a schematic tile map shaded by reported cases
- Global search box in the top bar for diseases, states and districts
- Health data visualization
- Data analysis
- Interactive dashboard

## How to Run
1. Install Python
2. Install required packages
3. Run the Flask application
4. Open the local URL in a browser
